# 创乐博 MakeBit 扩展板库

micro:bit V2 创乐博 MakeBit 小车扩展板的 Blockly 积木库，控制小车电机、舵机、车载风扇、蜂鸣器、RGB 探照灯（预设色 + 自定义色 + 特效 + 开关），并支持外接 SR04 超声波测距。

## Supported Boards

- BBC micro:bit V2（内核 `n-able-Arduino:arm-ble:BBCmicrobitV2`）
- 小车驱动板：板载 PCA9685（I2C 地址 0x41，SCL/SDA 使用 P19/P20）
- RGB 探照灯：通道 0/1/2（两个探照灯并联，同步变色）；P16 未被本库占用

## Description

按创乐博 cbit 扩展的功能移植：右电机接 PCA9685 通道 12/13，左电机接通道 15/14（v1.7.0 按实车测试修正了左右通道映射，修复左/右转与原地旋转方向相反的问题；v1.8.0 新增前进跑偏校正），车载舵机接通道 3（600–2400µs），车载风扇接通道 4/5，RGB 探照灯接通道 0/1/2（八色预设 + 自定义 RGB + 流水/彩虹/呼吸/闪烁特效 + 白灯开关 + 全局亮度，两个探照灯并联同步）。另有低电平触发的有源蜂鸣器积木，以及外接 SR04 超声波测距积木（发射/接收引脚可选，返回厘米，超时返回 0）。

## Quick Start

1. 拖入「初始化小车」积木（放在 setup 中）。
2. 用「小车 前进 速度 255」「小车舵机 角度 90」等积木控制动作，速度范围 0–255；前进跑偏时用「小车 前进校正 左/右」调小偏移反侧的百分比（0–100，默认100不校正）。
3. 「探照灯 颜色」「探照灯 亮/灭」「探照灯特效 彩虹」「探照灯 红/绿/蓝」等积木控制灯光（预设颜色、特效、亮灯与自定义RGB统一用「探照灯 亮度」全局亮度控制，v1.8.1 起亮/灭积木不再有独立亮度，v1.8.2 起自定义RGB也受全局亮度影响）；特效积木为阻塞执行，结束后继续后续程序。
4. 「超声波 发射 P1 接收 P2 距离(cm)」为外接 SR04 模块测距（单位厘米，单次测量含约 30ms 超时等待；避开 P16/P19/P20 等已占用引脚）。
