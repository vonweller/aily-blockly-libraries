# SdFat storage

Fast FAT16, FAT32, and exFAT SD card access.

## Library Info

| Field | Value |
|-------|-------|
| Package | @aily-project/lib-sdfat |
| Version | 0.1.0 |

| License | MIT |

## Supported Boards

Arduino AVR, Arduino SAMD, Arduino UNO R4, ESP32, ESP8266, RP2040

## Description

Fast FAT16, FAT32, and exFAT SD card access.

## Quick Start

1. Enable `@aily-project/lib-sdfat` in Aily Blockly.
2. Add the library blocks, initialize hardware in `arduino_setup()`, then use read/write blocks in `arduino_loop()`.
